# RealReview - Full Stack Real Estate Listing Platform

## Overview

RealReview is a real estate listing web application where users can register, login, add property listings with images, and search/filter listings by location. It is built using:

- React (Frontend)
- Flask (Backend)
- PostgreSQL (Database)
- JWT for authentication
- AWS EC2 for deployment
- Tailwind CSS for styling

## Features

- User registration and login with JWT authentication
- Add new property listings with image upload
- Filter listings by location
- Responsive and mobile-friendly UI
